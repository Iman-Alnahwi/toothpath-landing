# ToothPath — الموقع التعريفي

صفحة الهبوط العامّة لـ**ToothPath**، نظام إدارة معامل الأسنان.

> **مستودع منفصل عن التطبيق، بقصد.**
> كود النظام يحمل نموذج المجال وقاعدة البيانات وبيانات عيادات حقيقية.
> هذا المستودع عامّ، ولا يستورد ولا سطرًا من ذاك — فما بيه شي يتسرّب.

---

## شنو بيه، وشنو مو بيه

| موجود | غير موجود |
|---|---|
| صفحتان: `/` و `/privacy` | جداول قاعدة البيانات ومخططها |
| أسماء المراحل الثمان (`shared/stages.ts`) | نموذج المجال (858 سطرًا بالتطبيق) |
| أعمار المستحقات — أربع فئات | حساب المستحقات نفسه |
| قاعدتا التحقّق: الاسم والهاتف | باقي قواعد التحقّق |
| نصوص الصفحتين فقط (166 مفتاحًا) | قاموس التطبيق (1,511 سطرًا = مواصفة المنتج) |
| مدن العراق | أي بيانات عيادة أو طبيب أو مريض |

---

## التشغيل

```bash
pnpm install
cp .env.example .env      # ثم املأ أرقام التواصل
pnpm dev
```

## النشر

```bash
pnpm build && node .output/server/index.mjs
```

يشتغل على أي مضيف يدعم Node. **الاستمارة تحتاج خادمًا** — `pnpm generate` وحده ما يكفي.

## الإعدادات

كلها من `.env`، ولا واحد منها بالمستودع:

| المتغيّر | شنو يسوّي |
|---|---|
| `NUXT_PUBLIC_CONTACT_*` | الهاتف والواتساب والبريد بالتذييل. **عامّة** — يشوفها الزائر، وهذا مقصود لأنها مطبوعة بالصفحة أصلاً |
| `NUXT_PLANS_URL` | رابط `/api/public/plans` بالتطبيق الحيّ. **ضعه بالإنتاج** — بدونه تُقرأ الأسعار من `config/plans.ts`، ويصير للسعر بيتان |
| `NUXT_DEMO_FORWARD_URL` | يمرّر كل طلب للتطبيق الحيّ بدل تخزينه هنا. **خادمي** |

### ليش `PUBLIC_` مو مستوى أمان

كل ما تحت `runtimeConfig.public` **ينكتب داخل الـHTML** ويوصل كل زائر. لذا `NUXT_PLANS_URL` و`NUXT_DEMO_FORWARD_URL` **بلا** بادئة `PUBLIC_`: هما عنوان تطبيقك، وما ينقرآن إلا بالخادم.

*(قيست هذا فعلاً: لمّا كان `plansUrl` تحت `public`، عنوان التطبيق كان ظاهرًا بمصدر صفحة الموقع.)*

## طلبات العرض

بلا `NUXT_DEMO_FORWARD_URL` تُخزَّن الطلبات بـ`data/requests.jsonl` — **مستثنى بـ`.gitignore`**، لأنه أرقام هواتف أشخاص حقيقيين.

`POST /api/demo` هو **الكتابة المجهولة الوحيدة** بالمشروع، فعنده:
- تحقّق بنفس دوال `shared/validation.ts` اللي تستعملها الاستمارة
- حدّ إرسال: 5 طلبات بالساعة لكل IP → `429`
- سقف طول لكل حقل
- الردّ `{ ok: true }` فقط — ما يعكس شي ممّا انخزن

## عند تعديل النظام

ما أكو استيراد يربط المستودعين، وهذا ثمن الفصل. إذا تغيّر بالتطبيق:

- **اسم مرحلة** → `shared/stages.ts`
- **فئة عمر مستحقّات** → `shared/ageing.ts`
- **قاعدة الهاتف** → `shared/validation.ts`
- **سعر** → لا شي، إذا `NUXT_PLANS_URL` مضبوط. وإلا `config/plans.ts`
